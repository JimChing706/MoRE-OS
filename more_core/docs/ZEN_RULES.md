## 📜 第一章：安全之锚 (SAFETY ANCHOR)

### 1.1 零信任原则

```
┌─────────────────────────────────────────────────────────────────────┐
│  ZEN-01: 永不信任,始终验证                                          │
│                                                                      │
│  ▸ 所有用户输入必须验证                                             │
│  ▸ 所有外部调用必须鉴权                                             │
│  ▸ 所有LLM输出必须审查                                              │
│  ▸ 所有系统组件必须隔离                                             │
└─────────────────────────────────────────────────────────────────────┘
```

**实施规则**:
- ❌ 禁止: `eval(user_input)` - 任何用户输入不得直接执行
- ✅ 必须: `sanitize(user_input)` → 验证 → 白名单检查
- ❌ 禁止: 无限制的文件系统访问
- ✅ 必须: 沙箱限制 + 路径遍历防护

### 1.2 最小权限原则

```
┌─────────────────────────────────────────────────────────────────────┐
│  ZEN-02: 权限如指尖沙,松手即逝                                       │
│                                                                      │
│  ▸ 默认拒绝,显式允许                                                │
│  ▸ 任务完成即回收权限                                               │
│  ▸ 敏感操作需要二次确认                                             │
│  ▸ RBAC权限粒度到原子操作                                           │
└─────────────────────────────────────────────────────────────────────┘
```

### 1.3 纵深防御原则

```
┌─────────────────────────────────────────────────────────────────────┐
│  ZEN-03: 防御如洋葱,层层递进                                        │
│                                                                      │
│  L0 执行层: 沙箱执行 + 输出过滤                                     │
│  L1 编排层: 任务验证 + 资源限制                                     │
│  L2 进化层: 变体验证 + 隔离机制                                     │
│  L3 符号层: 规则推理 + 违规拦截                                     │
│  L4 认知层: 复杂度评估 + 风险标记                                   │
│  L5 元认知层: 权限校验 + 行为审计                                   │
└─────────────────────────────────────────────────────────────────────┘
```
