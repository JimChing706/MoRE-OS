## 五、自迭代工作流

### 完整流程

```
1. TaskRequest (allow_self_improvement=True)
       ↓
2. LayerRouter → L5 → L2 → L1 → L0
       ↓
3. L5: Metacognition.calibrate()
       ↓
4. L2: DGMEngine.evolve()
       ├── snapshot()     → 获取最佳父代
       ├── propose_variant() → 生成变体
       └── evaluate_variant() → 基准评估
       ↓
5. 验证通过 → 归档
   验证失败 → 隔离 + 事件报告
```

### 配置项

| 设置 | 默认值 | 说明 |
|------|--------|------|
| enable_evolution | False | 启用DGM进化 |
| enable_metacognition | False | 启用元认知 |
| enable_symbolic | True | 启用符号推理 |
